Atur Jam Result (Multi-Slot)

VPN Quick Connect (EU)

Ini tidak memasang VPN di situs. Kita hanya memicu aplikasi VPN (deep link), lalu membuka pasaran otomatis.

Contoh umum: NordVPN nordvpn://connect?country=de • Surfshark surfshark://connect?server=nl
Express/Proton bervariasi — jika ragu gunakan “Custom”.

Panduan Cepat

  • DONE: Tandai setelah menonton (tersimpan harian, auto-reset esok hari).
  • Jam Result: Otomatis terdeteksi dari nama (mis. 0130/0930/1400/1530/1630/2100/2330). Kamu bisa Edit Jam dan Tambah Slot per pasaran.
  • Countdown: Per slot + highlight Next paling dekat.
  • VPN EU: Setel di “Quick Connect”. Gunakan “Buka via EU VPN” pada kartu atau “Open All AMERICA via EU VPN”.
  • Notif: Aktifkan dari toolbar (Notifikasi: ON). Alarm muncul 5 menit sebelum result terdekat.
  • Zona Waktu: Default pakai jam perangkat. Opsi “Custom UTC Offset” untuk menafsirkan jam result.
  • Ekspor/Impor: Simpan semua pengaturan jadi file JSON, bisa dipindahkan antar device.
  • Shortcut: / fokus cari • Esc tutup modal • Ctrl/⌘+F fokus cari.
